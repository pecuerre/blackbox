# Visual design

Warm and calm, like a cosy independent bookshop. Not corporate.

- Colours: cream background (#FBF7F0), dark brown text (#3B2F2F), and a deep
  green (#2F5D50) for buttons and links.
- Headings in a serif font, body text in a clean sans-serif.
- Generous spacing, rounded corners, no harsh shadows.
- Book covers are always shown with a soft rounded edge.

Assets:

- `assets/logo.svg`: the logo, used in the header.
